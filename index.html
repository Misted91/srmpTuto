Prérequis

  • Un compte Minecraft Java Edition (acheté sur minecraft.net). La version Bedrock ne fonctionne pas.
  • Un PC sous Windows ou macOS.
  • Au moins 8 Go de RAM sur ton PC (16 Go conseillés).
  • Quelques Go d'espace disque libre pour les mods.
Comment ça marche ? Tu installes uniquement le mod AutoModpack. Quand tu te connectes à play.srmp.fun, le serveur t'envoie automatiquement tous les autres mods. Tu n'as rien d'autre à ajouter à la main.
1

Installer CurseForge

  1. Va sur curseforge.com/download/app et télécharge l'application pour ton système.
  2. Lance l'installateur et suis les instructions.
  3. Ouvre CurseForge. Au premier lancement, choisis le jeu Minecraft.
  4. CurseForge te demande où installer les fichiers de Minecraft. Garde le dossier par défaut, sauf si tu manques de place sur ton disque principal.
  5. Connecte ton compte Microsoft/Minecraft si CurseForge te le propose (sinon, ce sera fait au premier lancement du jeu).
Astuce : sur Windows, si une fenêtre « Windows a protégé votre ordinateur » apparaît, clique sur Informations complémentaires puis Exécuter quand même. L'installateur officiel de CurseForge est sans danger.
2

Créer un modpack NeoForge 1.21.1

  1. Dans CurseForge, clique sur Minecraft dans la barre de gauche, puis sur l'onglet My Modpacks.
  2. Clique sur + Create Custom Profile en haut à droite.
  3. Remplis le formulaire :
    Profile NameSRMP (ou le nom de ton choix)
    Game Version1.21.1
    ModloaderNeoForge
    Version du loaderla plus récente proposée (Recommended / Latest)
  4. Clique sur Create. CurseForge télécharge Minecraft et NeoForge : patiente jusqu'à la fin.
Attention : la version doit être exactement 1.21.1 avec NeoForge. Avec 1.21, 1.21.4, Forge ou Fabric, tu ne pourras pas te connecter.
3

Ajouter le mod AutoModpack

Méthode A : depuis CurseForge (recommandée)

  1. Ouvre ton profil SRMP en cliquant dessus.
  2. Clique sur Add More Content (ou Browse).
  3. Dans la barre de recherche, tape AutoModpack.
  4. Vérifie que c'est bien le mod AutoModpack de Skidam, puis clique sur Install.
  5. Reviens à ton profil : AutoModpack doit apparaître dans la liste des mods installés.

Méthode B : installation manuelle

  1. Télécharge le fichier .jar d'AutoModpack pour NeoForge 1.21.1 depuis Modrinth ou CurseForge.
  2. Dans CurseForge, sur ton profil, clique sur les trois points ⋮ puis Open Folder.
  3. Ouvre le dossier mods (crée-le s'il n'existe pas) et dépose-y le fichier .jar.
Important : n'ajoute aucun autre mod. AutoModpack s'occupe de tout installer à ta place depuis le serveur.
4

Régler la mémoire (RAM)

Un modpack a besoin de plus de mémoire que Minecraft classique. Sans ça, le jeu peut planter ou ramer.

  1. Dans CurseForge, clique sur l'icône ⚙ Settings (en bas à gauche).
  2. Va dans Game Specific → Minecraft.
  3. Dans Java Settings, règle Allocated Memory :
    PC avec 8 Go4 à 5 Go
    PC avec 16 Go6 à 8 Go
    PC avec 32 Go ou +8 à 10 Go
Astuce : ne donne jamais plus de la moitié de la RAM de ton PC. Allouer trop de mémoire ralentit le jeu au lieu de l'accélérer.
5

Premier lancement du jeu

  1. Sur ton profil SRMP, clique sur le gros bouton Play.
  2. Le launcher Minecraft s'ouvre. Connecte-toi avec ton compte Microsoft si on te le demande, puis clique sur Jouer.
  3. Le premier démarrage peut prendre une ou deux minutes. Attends d'arriver sur le menu principal de Minecraft.
6

Se connecter à play.srmp.fun et télécharger le modpack

  1. Dans le menu principal, clique sur Multijoueur.
  2. Clique sur Ajouter un serveur.
  3. Remplis :
    Nom du serveurSRMP
    Adresse du serveur
  4. Clique sur Terminé, sélectionne le serveur puis clique sur Rejoindre le serveur.
  5. Vérification du serveur : AutoModpack affiche l'empreinte (fingerprint) du serveur. C'est normal, ce n'est pas un bug. Si le staff SRMP t'a donné l'empreinte (sur Discord par exemple), compare-la ou colle-la dans le champ, puis valide.
  6. AutoModpack te propose d'installer le modpack du serveur : accepte.
  7. Le téléchargement des mods démarre. Laisse-le se terminer sans fermer le jeu : selon ta connexion, ça peut prendre quelques minutes.
  8. Une fois terminé, AutoModpack te demande de redémarrer le jeu. Accepte ou ferme Minecraft.
Ne coupe pas le téléchargement en cours de route. Si ça arrive, relance simplement le jeu et reconnecte-toi au serveur : AutoModpack reprendra là où il s'était arrêté.
7

Rejoindre le serveur

  1. Si le jeu ne s'est pas relancé tout seul, retourne dans CurseForge et clique à nouveau sur Play sur ton profil SRMP.
  2. Ce lancement est plus long que d'habitude : NeoForge charge maintenant tous les mods du serveur.
  3. Va dans Multijoueur, sélectionne SRMP et clique sur Rejoindre le serveur.
  4. Tu es connecté. Bon jeu sur play.srmp.fun ! 🎉

🔄 Mettre à jour le modpack

Avec AutoModpack, tu n'as presque rien à faire : les mises à jour sont automatiques.

  • Au lancement du jeu : AutoModpack vérifie si le modpack du serveur a changé. Si c'est le cas, il télécharge les nouveaux fichiers tout seul.
  • Si une mise à jour arrive pendant que tu joues : à ta prochaine connexion, AutoModpack télécharge les changements et te demande de redémarrer. Ferme le jeu puis relance-le depuis CurseForge.
  • Si le serveur te refuse (mods différents) : ferme complètement Minecraft, relance-le depuis CurseForge puis reconnecte-toi. La mise à jour se fera à ce moment-là.
Ne mets pas à jour les mods toi-même dans CurseForge (bouton Update). Les versions doivent être celles du serveur, et AutoModpack s'en occupe. Seule exception : si le staff annonce une nouvelle version d'AutoModpack, mets-le à jour depuis ton profil CurseForge.

🛠 Dépannage

« Incompatible client » ou « Mismatched mod list » quand je me connecte

Ton modpack n'est pas à jour. Ferme complètement le jeu, relance-le depuis CurseForge et reconnecte-toi pour que AutoModpack télécharge les changements. Vérifie aussi que ton profil est bien en 1.21.1 + NeoForge.

AutoModpack ne propose rien quand je rejoins le serveur

Vérifie que le fichier AutoModpack est bien dans le dossier mods de ton profil SRMP (pas dans un autre profil), et qu'il s'agit de la version NeoForge 1.21.1.

Erreur de certificat ou d'empreinte (« fingerprint mismatch »)

L'empreinte affichée ne correspond pas à celle attendue. Vérifie l'adresse (play.srmp.fun), puis contacte le staff sur Discord avant d'aller plus loin. Ne force pas la connexion.

Le jeu plante au démarrage ou rame énormément

Augmente la RAM allouée (voir étape 4) et mets à jour les pilotes de ta carte graphique. Si ça plante toujours, envoie le fichier logs/latest.log (dossier du profil → Open Folder) au staff.

Je veux repartir de zéro

Dans le dossier du profil (⋮ → Open Folder), supprime le dossier automodpack, puis relance le jeu et reconnecte-toi au serveur : tout sera retéléchargé. Tu peux aussi supprimer le profil dans CurseForge et reprendre ce guide à l'étape 2.

Je peux ajouter mes propres mods (minimap, shaders…) ?

Seulement les mods « côté client » que le staff autorise. Demande sur le Discord avant d'en ajouter un : un mod non compatible peut empêcher la connexion.
