Requirements

  • A Minecraft Java Edition account (bought on minecraft.net). Bedrock Edition will not work.
  • A Windows or macOS computer.
  • At least 8 GB of RAM in your computer (16 GB recommended).
  • A few GB of free disk space for the mods.
How does it work? You only install the AutoModpack mod. When you connect to play.srmp.fun, the server automatically sends you all the other mods. You don't need to add anything else by hand.
1

Install CurseForge

  1. Go to curseforge.com/download/app and download the app for your system.
  2. Run the installer and follow the instructions.
  3. Open CurseForge. On first launch, select the game Minecraft.
  4. CurseForge asks where to install the Minecraft files. Keep the default folder unless your main drive is low on space.
  5. Link your Microsoft/Minecraft account if CurseForge offers it (otherwise you'll do it when you first launch the game).
Tip: on Windows, if a "Windows protected your PC" window appears, click More info then Run anyway. The official CurseForge installer is safe.
2

Create a NeoForge 1.21.1 modpack

  1. In CurseForge, click Minecraft in the left sidebar, then the My Modpacks tab.
  2. Click + Create Custom Profile in the top right.
  3. Fill in the form:
    Profile NameSRMP (or any name you like)
    Game Version1.21.1
    ModloaderNeoForge
    Loader versionthe newest one offered (Recommended / Latest)
  4. Click Create. CurseForge downloads Minecraft and NeoForge: wait until it's finished.
Warning: the version must be exactly 1.21.1 with NeoForge. With 1.21, 1.21.4, Forge or Fabric, you won't be able to connect.
3

Add the AutoModpack mod

Method A: from CurseForge (recommended)

  1. Open your SRMP profile by clicking on it.
  2. Click Add More Content (or Browse).
  3. In the search bar, type AutoModpack.
  4. Make sure it's the AutoModpack mod by Skidam, then click Install.
  5. Go back to your profile: AutoModpack should appear in the list of installed mods.

Method B: manual install

  1. Download the AutoModpack .jar file for NeoForge 1.21.1 from Modrinth or CurseForge.
  2. In CurseForge, on your profile, click the three dots ⋮ then Open Folder.
  3. Open the mods folder (create it if it doesn't exist) and drop the .jar file into it.
Important: don't add any other mods. AutoModpack installs everything for you from the server.
4

Set the memory (RAM)

A modpack needs more memory than vanilla Minecraft. Without it, the game may crash or lag.

  1. In CurseForge, click the ⚙ Settings icon (bottom left).
  2. Go to Game Specific → Minecraft.
  3. Under Java Settings, set Allocated Memory:
    PC with 8 GB4 to 5 GB
    PC with 16 GB6 to 8 GB
    PC with 32 GB or more8 to 10 GB
Tip: never allocate more than half of your computer's RAM. Allocating too much memory slows the game down instead of speeding it up.
5

First game launch

  1. On your SRMP profile, click the big Play button.
  2. The Minecraft Launcher opens. Sign in with your Microsoft account if asked, then click Play.
  3. The first start can take a minute or two. Wait until you reach the Minecraft main menu.
6

Connect to play.srmp.fun and download the modpack

  1. From the main menu, click Multiplayer.
  2. Click Add Server.
  3. Fill in:
    Server NameSRMP
    Server Address
  4. Click Done, select the server, then click Join Server.
  5. Server verification: AutoModpack shows the server's fingerprint. This is normal, not a bug. If the friend who runs the server sent you the fingerprint, compare it or paste it into the field, then confirm.
  6. AutoModpack offers to install the server's modpack: accept.
  7. The mods start downloading. Let it finish without closing the game: depending on your connection, it can take a few minutes.
  8. When it's done, AutoModpack asks you to restart the game. Accept, or close Minecraft.
Don't interrupt the download. If it does get interrupted, just restart the game and reconnect to the server: AutoModpack will pick up where it left off.
7

Join the server

  1. If the game didn't restart on its own, go back to CurseForge and click Play on your SRMP profile again.
  2. This launch takes longer than usual: NeoForge is now loading all of the server's mods.
  3. Go to Multiplayer, select SRMP and click Join Server.
  4. You're in. Have fun on play.srmp.fun! 🎉

🔄 Updating the modpack

With AutoModpack, there's almost nothing to do: updates are automatic.

  • When the game starts: AutoModpack checks whether the server's modpack has changed. If it has, it downloads the new files on its own.
  • If an update comes out while you're playing: the next time you connect, AutoModpack downloads the changes and asks you to restart. Close the game, then launch it again from CurseForge.
  • If the server rejects you (mismatched mods): fully close Minecraft, launch it again from CurseForge and reconnect. The update will happen then.
Don't update the mods yourself in CurseForge (the Update button). The versions must match the server's, and AutoModpack takes care of that. The only exception: if the person who runs the server says AutoModpack itself needs updating, update it from your CurseForge profile.

🛠 Troubleshooting

"Incompatible client" or "Mismatched mod list" when I connect

Your modpack is out of date. Fully close the game, launch it again from CurseForge and reconnect so AutoModpack can download the changes. Also check that your profile is set to 1.21.1 + NeoForge.

AutoModpack doesn't offer anything when I join the server

Check that the AutoModpack file is in the mods folder of your SRMP profile (not another profile), and that it's the NeoForge 1.21.1 version.

Certificate or fingerprint error ("fingerprint mismatch")

The fingerprint shown doesn't match the expected one. Double-check the address (play.srmp.fun), then ask the friend who runs the server before going any further. Don't force the connection.

The game crashes on startup or lags a lot

Increase the allocated RAM (see step 4) and update your graphics card drivers. If it still crashes, send the logs/latest.log file (profile folder → Open Folder) to the friend who runs the server.

I want to start over from scratch

In the profile folder (⋮ → Open Folder), delete the automodpack folder, then launch the game and reconnect to the server: everything will be downloaded again. You can also delete the profile in CurseForge and restart this guide from step 2.

Can I add my own mods (minimap, shaders…)?

Only client-side mods, and ask the group first: an incompatible mod can prevent you from connecting.
